# Task types and hooks

Defines core interface declarations—including dataclasses, protocols, and hook signatures—used to build custom tasks. Concrete task-info providers reside within individual task packages to keep domain-specific logic (such as costs or goal conditions) decoupled from core primitives, with initial scaffolding generated automatically by the designer.
