# CAMRN FIVE STAR (SIE.CAMRN5) into JFK

Version `0`.
Arrivals into JFK on the CAMRN FIVE STAR (SIE.CAMRN5): from SIE VORTAC on SIE R-049 and DPK R-221 to CAMRN, crossing HOGGS at FL180 and CAMRN at 11000 and 250 KT, as the chart's planning information expects. Two streams feed SIE in trail, on J121 from RADDS and on oceanic B24 from FISSH. Jets only. Done at CAMRN, where JFK approach would vector them to final.


Generated by the bluesky-sandbox Environment Designer.

```
camrn_five/
  design.json   # original DesignSpec, reloadable in the designer
  scenario.py   # geometry / spawn / queryables / Scenario
  config.py     # static EnvConfig fields/settings
  setup.py      # module-level helpers / constants / task-info providers
  env.py        # hooks / BlueskyEnv subclass
  __main__.py   # python -m camrn_five  (smoke rollout)
```

## Use

```python
from camrn_five import Env
env = Env(render_mode="pygame")  # "pygame" | "panda3d" | "qtgl" | None (headless)
obs, infos = env.reset(seed=0)
actions = {agent: env.action_space(agent).sample() for agent in env.agents}
next_obs, rewards, terminations, truncations, infos = env.step(actions)
costs = {agent: info["cost"] for agent, info in infos.items()}  # this task defines a cost
```

Each is a dict keyed by agent. A reward or cost is a number, or an array of
components if the task's hook returns one.

Reload `design.json` in the designer, or edit `scenario.py` for
geometry/spawn/queryables, `config.py` for fields and simulator settings,
`setup.py` for the helpers the hooks lean on, and `env.py` for hooks, reward,
and episode termination.
